# Simulado VemMED

Página de captura da VemMED para solicitar acesso a Simulado VemMED, desenvolvida com Astro. O formulário está integrado ao Mautic (ID 18).

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:4321 no navegador.

## Build

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```
